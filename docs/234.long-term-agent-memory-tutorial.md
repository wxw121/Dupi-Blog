## 它解决什么问题

```text
问题场景：

用户 Alice 第一次使用 Agent：
  "我喜欢简洁的回答，不要太啰嗦"

一周后，新会话：
  Agent 又给了冗长的回答
  Alice: "我上次说了我喜欢简洁的！"
  Agent: "抱歉，我没有之前的记录"

没有长期记忆：
- 每次会话从零开始
- 用户反复表达偏好
- Agent 无法积累经验
- 体验像"金鱼记忆"

有长期记忆但设计差：
- 记了不该记的（隐私）
- 记错了（幻觉固化）
- 记太多（检索噪声）
- 用户无法删除（合规风险）

正确做法：
- 只记稳定的、有价值的信息
- 写入前验证和确认
- 支持衰减和删除
- 用户有完全控制权
```

## 核心概念

```text
长期记忆的三大类别：

1. 用户偏好 (Preferences)
   ━━━━━━━━━━━━━━━━━━━━━━━
   - 沟通风格：简洁/详细/技术/通俗
   - 格式偏好：代码用 tab/空格，回答用中文/英文
   - 交互习惯：喜欢确认/喜欢直接执行
   特点：变化慢，置信度高，一旦确认长期有效

2. 用户事实 (Facts)
   ━━━━━━━━━━━━━━━━━━━━━━━
   - 个人信息：职业、技术栈、项目
   - 环境信息：操作系统、常用工具
   - 关系信息：团队成员、项目归属
   特点：偶尔变化，需要版本管理

3. 历史经验 (Episodes)
   ━━━━━━━━━━━━━━━━━━━━━━━
   - 成功方案：上次怎么解决的
   - 失败教训：什么方法不管用
   - 交互模式：用户通常怎么提问
   特点：随时间衰减，可能被新经验覆盖

存储模型：
┌────────────────────────────────────────────┐
│ LongTermMemory                             │
├────────────────────────────────────────────┤
│ id: str                                    │
│ user_id: str                               │
│ category: preference | fact | episode      │
│ content: str                               │
│ embedding: vector                          │
│ confidence: float (0-1)                    │
│ importance: float (0-1)                    │
│ source_session: str                        │
│ created_at: timestamp                      │
│ last_accessed: timestamp                   │
│ access_count: int                          │
│ version: int                               │
│ status: active | decayed | archived        │
│ ttl: optional timestamp                    │
└────────────────────────────────────────────┘

生命周期：
  提取 → 候选 → 确认 → 活跃 → 衰减 → 归档/删除
```

## 最小示例

```python
"""最小示例：长期记忆基本操作"""
from dataclasses import dataclass, field
from enum import Enum
from datetime import datetime
import uuid


class MemoryCategory(Enum):
    PREFERENCE = "preference"
    FACT = "fact"
    EPISODE = "episode"


class MemoryStatus(Enum):
    CANDIDATE = "candidate"
    ACTIVE = "active"
    DECAYED = "decayed"
    ARCHIVED = "archived"


@dataclass
class LongTermMemory:
    """长期记忆条目"""
    id: str = field(default_factory=lambda: uuid.uuid4().hex[:12])
    user_id: str = ""
    category: MemoryCategory = MemoryCategory.FACT
    content: str = ""
    confidence: float = 0.5
    importance: float = 0.5
    status: MemoryStatus = MemoryStatus.CANDIDATE
    source_session: str = ""
    created_at: datetime = field(default_factory=datetime.now)
    last_accessed: datetime = field(default_factory=datetime.now)
    access_count: int = 0
    version: int = 1

    def activate(self) -> None:
        self.status = MemoryStatus.ACTIVE
        self.confidence = min(1.0, self.confidence + 0.2)

    def decay(self, factor: float = 0.9) -> None:
        self.confidence *= factor
        if self.confidence < 0.3:
            self.status = MemoryStatus.DECAYED

    def access(self) -> None:
        self.access_count += 1
        self.last_accessed = datetime.now()
        # 被访问时恢复一些置信度
        self.confidence = min(1.0, self.confidence + 0.05)


class SimpleLongTermStore:
    """简单长期记忆存储"""

    def __init__(self):
        self._memories: dict[str, LongTermMemory] = {}

    def add(self, memory: LongTermMemory) -> str:
        self._memories[memory.id] = memory
        return memory.id

    def get_active(self, user_id: str) -> list[LongTermMemory]:
        return [
            m for m in self._memories.values()
            if m.user_id == user_id
            and m.status == MemoryStatus.ACTIVE
        ]

    def confirm(self, memory_id: str) -> bool:
        mem = self._memories.get(memory_id)
        if mem and mem.status == MemoryStatus.CANDIDATE:
            mem.activate()
            return True
        return False

    def delete(self, memory_id: str) -> bool:
        return self._memories.pop(memory_id, None) is not None

    def decay_all(self, user_id: str) -> int:
        count = 0
        for m in self._memories.values():
            if m.user_id == user_id and m.status == MemoryStatus.ACTIVE:
                m.decay()
                if m.status == MemoryStatus.DECAYED:
                    count += 1
        return count


# 使用
store = SimpleLongTermStore()

# 从对话中提取偏好
mem = LongTermMemory(
    user_id="alice",
    category=MemoryCategory.PREFERENCE,
    content="用户偏好简洁回答，不喜欢冗长解释",
    confidence=0.8,
    importance=0.9,
    source_session="sess-001",
)
store.add(mem)
store.confirm(mem.id)

# 新会话中检索
active = store.get_active("alice")
for m in active:
    print(f"[{m.category.value}] {m.content} (置信度: {m.confidence:.1f})")
```

## 工程化版本

```python
"""工程化版本：完整的长期记忆系统"""
from __future__ import annotations

import hashlib
import logging
import time
import uuid
from dataclasses import dataclass, field
from enum import Enum
from typing import Any, Callable

logger = logging.getLogger(__name__)


# ─── 数据模型 ───────────────────────────────────────────────

class MemoryCategory(Enum):
    PREFERENCE = "preference"
    FACT = "fact"
    EPISODE = "episode"


class MemoryStatus(Enum):
    CANDIDATE = "candidate"
    PENDING_CONFIRM = "pending_confirm"
    ACTIVE = "active"
    DECAYED = "decayed"
    ARCHIVED = "archived"
    DELETED = "deleted"


@dataclass
class MemoryRecord:
    """长期记忆记录"""
    id: str = field(default_factory=lambda: uuid.uuid4().hex)
    user_id: str = ""
    category: MemoryCategory = MemoryCategory.FACT
    content: str = ""
    embedding: list[float] | None = None
    confidence: float = 0.5
    importance: float = 0.5
    status: MemoryStatus = MemoryStatus.CANDIDATE
    tags: list[str] = field(default_factory=list)
    source_session: str = ""
    source_turn: int = 0
    created_at: float = field(default_factory=time.time)
    updated_at: float = field(default_factory=time.time)
    last_accessed: float = field(default_factory=time.time)
    access_count: int = 0
    version: int = 1
    superseded_by: str | None = None  # 被哪条记忆替代
    metadata: dict[str, Any] = field(default_factory=dict)

    def content_hash(self) -> str:
        return hashlib.sha256(self.content.encode()).hexdigest()[:16]

    def effective_score(self) -> float:
        """有效得分 = 重要度 × 置信度 × 新鲜度"""
        age_days = (time.time() - self.last_accessed) / 86400
        freshness = 0.5 ** (age_days / 90)  # 90天半衰期
        return self.importance * self.confidence * freshness


# ─── 提取器 ─────────────────────────────────────────────────

@dataclass
class ExtractionResult:
    """提取结果"""
    content: str
    category: MemoryCategory
    confidence: float
    importance: float
    tags: list[str] = field(default_factory=list)


class MemoryExtractor:
    """从对话中提取长期记忆候选"""

    def __init__(self, llm_call: Callable[[str], str] | None = None):
        self._llm_call = llm_call

    def extract(
        self, conversation: list[dict[str, str]], session_id: str
    ) -> list[ExtractionResult]:
        if self._llm_call:
            return self._llm_extract(conversation)
        return self._rule_extract(conversation)

    def _llm_extract(
        self, conversation: list[dict[str, str]]
    ) -> list[ExtractionResult]:
        dialogue = "\n".join(
            f"{m['role']}: {m['content']}" for m in conversation
        )
        prompt = f"""从以下对话中提取值得长期记住的信息。

对话：
{dialogue}

请提取：
1. 用户偏好（沟通风格、格式要求等）
2. 用户事实（职业、技术栈、环境等）
3. 重要经验（解决方案、失败教训等）

对每条输出 JSON 格式：
{{"content": "...", "category": "preference|fact|episode",
  "confidence": 0.0-1.0, "importance": 0.0-1.0}}

只提取明确表达的、稳定的信息。不确定的不要提取。"""

        response = self._llm_call(prompt)
        # 解析 JSON（简化）
        import json
        results = []
        try:
            items = json.loads(response)
            for item in items:
                results.append(ExtractionResult(
                    content=item["content"],
                    category=MemoryCategory(item["category"]),
                    confidence=item.get("confidence", 0.5),
                    importance=item.get("importance", 0.5),
                ))
        except (json.JSONDecodeError, KeyError):
            pass
        return results

    def _rule_extract(
        self, conversation: list[dict[str, str]]
    ) -> list[ExtractionResult]:
        """基于规则的提取"""
        results = []
        preference_keywords = [
            "我喜欢", "我偏好", "请不要", "我希望",
            "我习惯", "我通常", "以后都",
        ]
        fact_keywords = [
            "我是", "我用", "我的", "我在",
            "我们团队", "我的项目",
        ]
        for msg in conversation:
            if msg["role"] != "user":
                continue
            content = msg["content"]
            # 偏好检测
            if any(kw in content for kw in preference_keywords):
                results.append(ExtractionResult(
                    content=content,
                    category=MemoryCategory.PREFERENCE,
                    confidence=0.7,
                    importance=0.8,
                    tags=["preference"],
                ))
            # 事实检测
            elif any(kw in content for kw in fact_keywords):
                results.append(ExtractionResult(
                    content=content,
                    category=MemoryCategory.FACT,
                    confidence=0.6,
                    importance=0.6,
                    tags=["fact"],
                ))
        return results


# ─── 冲突检测 ───────────────────────────────────────────────

class ConflictDetector:
    """记忆冲突检测"""

    def __init__(self, similarity_fn: Callable[[str, str], float] | None = None):
        self._similarity = similarity_fn or self._default_similarity

    def find_conflicts(
        self, new_content: str, existing: list[MemoryRecord]
    ) -> list[tuple[MemoryRecord, float]]:
        """找到与新内容冲突的已有记忆"""
        conflicts = []
        for record in existing:
            sim = self._similarity(new_content, record.content)
            if sim > 0.7:  # 高相似度 = 可能冲突
                conflicts.append((record, sim))
        return conflicts

    @staticmethod
    def _default_similarity(a: str, b: str) -> float:
        """简单字符重叠相似度"""
        set_a = set(a)
        set_b = set(b)
        if not set_a or not set_b:
            return 0.0
        return len(set_a & set_b) / min(len(set_a), len(set_b))


# ─── 衰减管理 ───────────────────────────────────────────────

class DecayManager:
    """记忆衰减管理"""

    def __init__(
        self,
        half_life_days: float = 90,
        min_confidence: float = 0.2,
        access_boost: float = 0.05,
    ):
        self.half_life_days = half_life_days
        self.min_confidence = min_confidence
        self.access_boost = access_boost

    def apply_decay(self, record: MemoryRecord) -> None:
        """应用时间衰减"""
        age_days = (time.time() - record.last_accessed) / 86400
        decay_factor = 0.5 ** (age_days / self.half_life_days)
        record.confidence *= decay_factor
        if record.confidence < self.min_confidence:
            record.status = MemoryStatus.DECAYED

    def boost_on_access(self, record: MemoryRecord) -> None:
        """访问时提升"""
        record.access_count += 1
        record.last_accessed = time.time()
        record.confidence = min(1.0, record.confidence + self.access_boost)
        if record.status == MemoryStatus.DECAYED:
            if record.confidence >= self.min_confidence:
                record.status = MemoryStatus.ACTIVE


# ─── 核心管理器 ─────────────────────────────────────────────

class LongTermMemoryManager:
    """长期记忆管理器"""

    def __init__(
        self,
        extractor: MemoryExtractor | None = None,
        conflict_detector: ConflictDetector | None = None,
        decay_manager: DecayManager | None = None,
        max_per_user: int = 500,
    ):
        self.extractor = extractor or MemoryExtractor()
        self.conflict_detector = conflict_detector or ConflictDetector()
        self.decay_manager = decay_manager or DecayManager()
        self.max_per_user = max_per_user
        self._store: dict[str, MemoryRecord] = {}
        self._stats = {
            "extractions": 0, "confirms": 0,
            "conflicts": 0, "decays": 0, "deletes": 0,
        }

    def ingest_session(
        self,
        user_id: str,
        conversation: list[dict[str, str]],
        session_id: str,
        auto_confirm: bool = False,
    ) -> list[MemoryRecord]:
        """从会话中提取并存储记忆"""
        extractions = self.extractor.extract(conversation, session_id)
        self._stats["extractions"] += len(extractions)

        new_records = []
        existing = self.get_all(user_id)

        for ext in extractions:
            # 去重
            ext_hash = hashlib.sha256(ext.content.encode()).hexdigest()[:16]
            if any(r.content_hash() == ext_hash for r in existing):
                continue

            # 冲突检测
            conflicts = self.conflict_detector.find_conflicts(
                ext.content, existing
            )
            if conflicts:
                self._stats["conflicts"] += 1
                # 标记冲突，等待解决
                for old, sim in conflicts:
                    logger.info(
                        f"冲突: '{ext.content[:30]}' vs '{old.content[:30]}'"
                    )

            record = MemoryRecord(
                user_id=user_id,
                category=ext.category,
                content=ext.content,
                confidence=ext.confidence,
                importance=ext.importance,
                tags=ext.tags,
                source_session=session_id,
                status=(
                    MemoryStatus.ACTIVE if auto_confirm
                    else MemoryStatus.CANDIDATE
                ),
            )
            self._store[record.id] = record
            new_records.append(record)

        return new_records

    def confirm(self, memory_id: str) -> bool:
        """确认候选记忆"""
        record = self._store.get(memory_id)
        if record and record.status == MemoryStatus.CANDIDATE:
            record.status = MemoryStatus.ACTIVE
            record.confidence = min(1.0, record.confidence + 0.2)
            self._stats["confirms"] += 1
            return True
        return False

    def reject(self, memory_id: str) -> bool:
        """拒绝候选记忆"""
        record = self._store.get(memory_id)
        if record:
            record.status = MemoryStatus.DELETED
            return True
        return False

    def get_all(
        self, user_id: str, active_only: bool = True
    ) -> list[MemoryRecord]:
        """获取用户所有记忆"""
        results = []
        for r in self._store.values():
            if r.user_id != user_id:
                continue
            if active_only and r.status != MemoryStatus.ACTIVE:
                continue
            results.append(r)
        results.sort(key=lambda r: r.effective_score(), reverse=True)
        return results

    def get_for_context(
        self, user_id: str, max_items: int = 10
    ) -> list[MemoryRecord]:
        """获取用于上下文的记忆（按有效得分排序）"""
        active = self.get_all(user_id, active_only=True)
        selected = active[:max_items]
        for r in selected:
            self.decay_manager.boost_on_access(r)
        return selected

    def update(
        self, memory_id: str, new_content: str, reason: str = ""
    ) -> bool:
        """更新记忆（创建新版本）"""
        old = self._store.get(memory_id)
        if not old:
            return False
        # 旧版本标记为已替代
        old.status = MemoryStatus.ARCHIVED
        # 创建新版本
        new_record = MemoryRecord(
            user_id=old.user_id,
            category=old.category,
            content=new_content,
            confidence=old.confidence,
            importance=old.importance,
            tags=old.tags,
            status=MemoryStatus.ACTIVE,
            version=old.version + 1,
            metadata={"supersedes": old.id, "reason": reason},
        )
        old.superseded_by = new_record.id
        self._store[new_record.id] = new_record
        return True

    def delete_user_data(self, user_id: str) -> int:
        """GDPR 删除：删除用户所有数据"""
        to_delete = [
            mid for mid, r in self._store.items()
            if r.user_id == user_id
        ]
        for mid in to_delete:
            del self._store[mid]
        self._stats["deletes"] += len(to_delete)
        return len(to_delete)

    def run_decay(self, user_id: str) -> int:
        """执行衰减"""
        count = 0
        for r in self._store.values():
            if r.user_id == user_id and r.status == MemoryStatus.ACTIVE:
                self.decay_manager.apply_decay(r)
                if r.status == MemoryStatus.DECAYED:
                    count += 1
        self._stats["decays"] += count
        return count

    def get_stats(self) -> dict:
        return dict(self._stats)


# ─── 使用示例 ───────────────────────────────────────────────

def demo():
    manager = LongTermMemoryManager()

    # 模拟会话
    conversation = [
        {"role": "user", "content": "你好，我是后端开发，主要用 Python 和 Go"},
        {"role": "assistant", "content": "你好！了解，你是后端开发。"},
        {"role": "user", "content": "我喜欢简洁的回答，代码注释用英文"},
        {"role": "assistant", "content": "好的，我会保持简洁。"},
        {"role": "user", "content": "上次那个 Redis 连接池的问题，用 max_connections=50 解决了"},
        {"role": "assistant", "content": "记录下来了。"},
    ]

    # 提取
    records = manager.ingest_session(
        user_id="alice",
        conversation=conversation,
        session_id="sess-001",
        auto_confirm=True,
    )
    print(f"提取了 {len(records)} 条记忆：")
    for r in records:
        print(f"  [{r.category.value}] {r.content[:50]}")

    # 新会话中检索
    context_memories = manager.get_for_context("alice", max_items=5)
    print(f"\n上下文记忆 ({len(context_memories)} 条):")
    for r in context_memories:
        print(f"  [{r.category.value}] {r.content[:50]} (score: {r.effective_score():.2f})")


if __name__ == "__main__":
    demo()
```

## 记忆提取与确认

```text
提取管道的四个阶段：

阶段 1：候选提取
━━━━━━━━━━━━━━━━
- 输入：会话对话记录
- 方法：LLM 提取 / 规则匹配 / NER
- 输出：候选记忆列表
- 关键：宁缺毋滥，不确定的不提取

阶段 2：质量过滤
━━━━━━━━━━━━━━━━
- 去重：和已有记忆对比
- 冲突检测：是否和已有记忆矛盾
- 敏感度检查：是否包含 PII
- 稳定性判断：是临时状态还是持久特征

阶段 3：确认
━━━━━━━━━━━━━━━━
- 高置信度（> 0.8）：自动确认
- 中置信度（0.5-0.8）：下次交互时隐式确认
- 低置信度（< 0.5）：丢弃或等更多证据
- 敏感信息：必须用户明确确认

阶段 4：持久化
━━━━━━━━━━━━━━━━
- 生成 embedding
- 写入数据库 + 向量库
- 建立索引
- 记录来源（可追溯）

隐式确认机制：
- Agent 使用某条记忆后，用户没有否认 → 置信度 +0.1
- Agent 使用某条记忆后，用户纠正 → 置信度 -0.3 或标记错误
- 多次被成功使用 → 逐步提升为高置信度
```

## 常见失败模式

```text
失败模式 1：幻觉固化
━━━━━━━━━━━━━━━━━━━━━━━━
症状：Agent "记住"了用户从未说过的话
原因：LLM 提取时产生幻觉，把推测当事实
后果：Agent 基于错误记忆行动，用户困惑
修复：
- 只提取用户明确表达的信息
- 提取后回显给用户确认
- 记忆带来源（哪轮对话），可追溯

失败模式 2：过度记忆
━━━━━━━━━━━━━━━━━━━━━━━━
症状：检索结果噪声大，不相关记忆干扰
原因：什么都记，没有过滤
后果：上下文被无关记忆占满
修复：
- 严格过滤：只记稳定的、可复用的
- "今天天气不错"不是记忆
- 定期清理低分记忆

失败模式 3：记忆过时
━━━━━━━━━━━━━━━━━━━━━━━━
症状：Agent 用旧信息回答（"你不是用 Java 吗？"）
原因：用户情况变了，记忆没更新
后果：回答不相关，用户觉得 Agent 不智能
修复：
- 时间衰减 + 访问频率
- 检测到矛盾时更新
- 重要事实定期确认

失败模式 4：隐私泄露
━━━━━━━━━━━━━━━━━━━━━━━━
症状：用户 A 的对话中出现用户 B 的信息
原因：检索时没有按 user_id 隔离
后果：严重隐私事故
修复：
- 所有查询强制带 user_id
- 存储层按用户分区
- 审计日志

失败模式 5：删除不彻底
━━━━━━━━━━━━━━━━━━━━━━━━
症状：用户要求删除后，信息仍然出现
原因：只删了主表，向量库/缓存/备份没清
后果：GDPR 违规
修复：
- 删除要级联：主表 + 向量库 + 缓存
- 异步清理备份
- 删除完成通知用户
```

## 什么时候不要这么做

```text
不需要长期记忆的场景：

1. 匿名/一次性交互
   - 没有用户身份，无法关联
   - 如：公共查询 Bot

2. 高频变化的信息
   - 实时股价、天气
   - 应该实时查询，不是"记住"

3. 已有外部数据源
   - 用户信息在 CRM 里
   - 直接查 CRM，不需要 Agent 自己记

4. 合规限制
   - 某些行业不允许存储用户对话
   - 金融、医疗有严格数据保留策略

5. 简单工具型 Agent
   - 只做格式转换、计算
   - 不需要"了解"用户

判断标准：
- 用户会回来吗？→ 是 → 可能需要
- 信息跨会话有价值吗？→ 是 → 需要
- 有外部数据源替代吗？→ 是 → 不需要
```

## 生产环境注意事项

```text
存储架构：

PostgreSQL（结构化数据）：
- 记忆元数据（id, user_id, category, status, confidence...）
- 版本历史
- 审计日志
- 索引：(user_id, status, category)

向量库（语义检索）：
- 记忆 embedding
- 按 user_id 分区（或 metadata 过滤）
- 推荐：Qdrant（支持 payload 过滤）

Redis（热缓存）：
- 用户 top-N 高频记忆
- TTL: 1 小时
- 减少数据库查询

加密：
- 敏感字段 AES-256 加密
- embedding 不需要加密（不可逆）
- 密钥用 KMS 管理

GDPR 合规：
- 支持"被遗忘权"：级联删除所有存储
- 数据可移植：导出用户所有记忆
- 明确告知：隐私政策说明记忆功能
- 同意机制：首次使用需用户同意

容量规划（10K 用户）：
- 每用户平均 100 条记忆 × 1KB = 100KB
- 总计 ~1GB 结构化数据
- 向量：100 × 1536 dim × 4B = 600KB/用户 → ~6GB
- Redis 缓存：~500MB
```

## 面试怎么讲

```text
面试官问：Agent 的长期记忆怎么设计？

回答框架（2 分钟）：

"长期记忆我分三类：偏好、事实、经验。

偏好是变化最慢的——'我喜欢简洁回答'，
一旦确认可以长期有效。

事实是偶尔变化的——'我用 Python'，
可能换工作就变了，需要版本管理。

经验是随时间衰减的——'上次用方案 A 解决了'，
90 天不用就降权。

写入流程是四步：
提取 → 过滤 → 确认 → 持久化。
关键是确认环节——高置信度自动确认，
中置信度隐式确认（用了用户没否认），
低置信度直接丢弃。

存储用 PostgreSQL + 向量库。
结构化查询走 PG，语义检索走向量库。
敏感字段加密，按 user_id 严格隔离。

我踩过的坑：
一开始用 LLM 提取记忆，结果它把推测当事实，
记了用户没说过的话。后来改成只提取明确表达的，
加上来源追溯，问题就少了。"

追问应对：
Q: 怎么处理记忆冲突？
A: 写入时做相似度检测，> 0.7 视为冲突。
   新信息覆盖旧记忆，但旧记忆归档保留。
   如果是高重要度记忆，提示用户确认。

Q: GDPR 删除怎么做？
A: 级联删除：PG 主表 + 向量库 + Redis 缓存。
   异步清理备份。24h 内完成，通知用户。
```

## 设计原则总结

```text
长期记忆设计的 7 条原则：

1. 宁缺毋滥
   - 不确定的不记
   - 临时的不记
   - 外部能查到的不记

2. 用户主权
   - 用户能查看所有记忆
   - 用户能修正错误
   - 用户能完全删除
   - 首次使用需同意

3. 可追溯
   - 每条记忆有来源（哪个会话、哪轮）
   - 有版本历史
   - 有修改审计

4. 衰减而非永存
   - 不被访问的记忆逐渐降权
   - 避免过时信息干扰

5. 隔离严格
   - 按 user_id 物理/逻辑隔离
   - 绝不跨用户泄露

6. 冲突可解
   - 检测冲突
   - 新覆盖旧
   - 保留历史

7. 透明使用
   - 告诉用户"我记住了什么"
   - 使用记忆时适当提及
   - 不偷偷用
```

```text
编程助手 Agent 的长期记忆设计：

记忆类别配置：

上下文组装（新会话开始时）：
- 取 top-5 偏好（基本不变）
- 取 top-3 事实（当前项目相关）
- 取 top-3 经验（和当前问题相关）
- 总计约 300 token
```
