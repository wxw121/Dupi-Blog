**参考答法（开发向）：**

**背景要点**：2024 年某个周四，同事小王兴冲冲地跑过来说：「我搞定了实时通知——用 WebSocket + Redis Pub/Sub + 心跳 + 自动重连 + Sticky Session！」

5. **评测**：离线指标 + 线上 shadow / 金丝雀。

**常见追问：**

### Q6. 比 WebSocket 更简单的服务端推送方案 能力要上生产，你会优先保证哪三件事？ {#q6}

| 维度 | 说明 |
|------|------|
| 类型 | 生产化 |
| 难度 | 高频 |
| 考点 | 生产落地 |

**参考答法（开发向）：**

结合 比 WebSocket 更简单的服务端推送方案 常见风险点：2024 年某个周四，同事小王兴冲冲地跑过来说：「我搞定了实时通知——用 WebSocket + Redis Pub/Sub + 心跳 + 自动重连 + Sticky Session！」

**推荐三件事**：
1. **SLO 与降级**：定义 P95/P99、错误预算；检索失败/模型超时时的兜底路径；
2. **可观测**：trace_id 贯穿；记录检索命中、token、工具调用、人工介入；
3. **变更安全**：配置与 Prompt 版本化；灰度 + 自动回滚条件；回归评测门禁。

面试时用 **一个真实指标** 收尾（如 citation 准确率、empty retrieval 率）。

**常见追问：**

- 如何做成本归因到租户/业务线？
- on-call 值班最需要哪三张大盘？
