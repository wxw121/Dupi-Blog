### Q1. 什么是 Markdown AST 分块？在 Markdown AST 分块 相关系统里它承担什么职责？ {#q1}

| 维度 | 说明 |
|------|------|
| 类型 | 概念题 |
| 难度 | 基础 |
| 考点 | 核心概念 · Markdown AST 分块 |

**参考答法（开发向）：**

**Markdown AST 分块**（Markdown AST Chunking）：在 Markdown **抽象语法树** 上遍历 **块级节点**（block-level nodes），以 **标题层级** 为主要切分边界，并遵守 **代码块、列表** 等结构单元的完整性约束，产出带 **章节元数据** 的文本块供 Embedding 索引。

直觉：**不是对着 字符串数到 500 就锯一刀，而是沿着「## 安装」「## 配置」这些章节接缝切**。

**工程语境（Markdown AST 分块）**：
- 解决什么：把「Markdown AST 分块」讲清楚时，要落到 **输入/输出、放在链路哪一层、失败时怎么办**；
- 常见误用：只会背定义，说不出和相邻组件的分工；
- 加分项：举一个线上或 demo 中的真实调用点（接口、配置项、监控指标）。

**常见追问：**

- Markdown AST 分块 和容易混淆的替代方案怎么选？
- 如果去掉 Markdown AST 分块 这一层，最先坏掉的是哪一环？
