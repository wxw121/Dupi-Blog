### Q2. 什么是 对比学习？在 对比学习完全指南（了解篇） 相关系统里它承担什么职责？ {#q2}

| 维度 | 说明 |
|------|------|
| 类型 | 概念题 |
| 难度 | 基础 |
| 考点 | 核心概念 · 对比学习 |

**参考答法（开发向）：**

**对比学习**（Contrastive Learning）：通过构造 **正例对**（应相似）与 **负例对**（应不相似），训练模型使正例在表示空间中 **靠近**、负例 **远离** 的一类学习方法。

直觉：**用「谁跟谁一伙、谁跟谁别一伙」来教模型画地图**——地图画好后，RAG 推理只是 **查地图**（25 篇）。

**工程语境（对比学习完全指南（了解篇））**：
- 解决什么：把「对比学习」讲清楚时，要落到 **输入/输出、放在链路哪一层、失败时怎么办**；

| 维度 | 说明 |
|------|------|
| 类型 | 概念题 |
| 难度 | 基础 |
| 考点 | 核心概念 · InfoNCE |

**参考答法（开发向）：**

**InfoNCE**（Noise Contrastive Estimation 一族）：在一个 batch 里，给定 **anchor**，有 **1 个正例** 和 **多个负例**，做「**相似度竞赛**」——让正例的相似度分数 **相对** 所有负例 **最高**。

### Q16. 对比学习完全指南（了解篇） 能力要上生产，你会优先保证哪三件事？ {#q16}

| 维度 | 说明 |
|------|------|
| 类型 | 生产化 |
| 难度 | 高频 |
| 考点 | 生产落地 |

**参考答法（开发向）：**

结合 对比学习完全指南（了解篇） 常见风险点：算法同学说「BGE 用 **对比损失** 预训练」；

**推荐三件事**：
1. **SLO 与降级**：定义 P95/P99、错误预算；检索失败/模型超时时的兜底路径；
2. **可观测**：trace_id 贯穿；记录检索命中、token、工具调用、人工介入；
3. **变更安全**：配置与 Prompt 版本化；灰度 + 自动回滚条件；回归评测门禁。

面试时用 **一个真实指标** 收尾（如 citation 准确率、empty retrieval 率）。

**常见追问：**

- 如何做成本归因到租户/业务线？
- on-call 值班最需要哪三张大盘？
