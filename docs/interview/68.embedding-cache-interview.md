### Q1. 什么是 Embedding 缓存？在 Embedding 缓存策略 相关系统里它承担什么职责？ {#q1}

| 维度 | 说明 |
|------|------|
| 类型 | 概念题 |
| 难度 | 基础 |
| 考点 | 核心概念 · Embedding 缓存 |

**参考答法（开发向）：**

**Embedding 缓存**（embedding cache）：以 **确定性键** 存储已算好的向量；请求前 **查键**，命中则 **直接取向量**，未命中再调模型并 **写回**。

直觉：**做过的坐标卡进抽屉**，下次别重新测绘。

**工程语境（Embedding 缓存策略）**：
- 解决什么：把「Embedding 缓存」讲清楚时，要落到 **输入/输出、放在链路哪一层、失败时怎么办**；
- 常见误用：只会背定义，说不出和相邻组件的分工；
- 加分项：举一个线上或 demo 中的真实调用点（接口、配置项、监控指标）。

**常见追问：**

- Embedding 缓存 和容易混淆的替代方案怎么选？
- 如果去掉 Embedding 缓存 这一层，最先坏掉的是哪一环？

|------|------|

| 难度 | 基础 |
| 考点 | 核心概念 · Cache-Aside |

**参考答法（开发向）：**

### Q11. 做 Embedding 缓存策略 时，哪些能力应在当前服务内实现，哪些应下沉到专用组件或另开服务？ {#q11}

| 维度 | 说明 |
|------|------|
| 类型 | 架构边界 |
| 难度 | 中等 |
| 考点 | 架构分层 |

**参考答法（开发向）：**

考察 **分层与职责单一**，避免一个服务包揽 Embedding 缓存策略 全链路。

**通常不在同一层硬做的**（示例）：
- ** CDN 边缘缓存、向量库内置缓存层实现、分布式一致性协议完整理论、加密向量密文检索。

**答题要点**：
- 当前层只保留 **决策 + 编排 + 领域状态**；
- IO 密集（向量库、对象存储、消息队列）通过稳定接口调用；
- 说清楚 **同步调用 vs 异步任务** 的切分依据（延迟预算、失败重试）。

**常见追问：**

- 团队很小、没有平台组时，边界会不会变？怎么避免过度拆分？
