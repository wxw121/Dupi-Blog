|------|------|
| 类型 | 概念题 |

| 考点 | 核心概念 · Layout |

**参考答法（开发向）：**

**Layout**（版面 / 版面分析）：理解页面上 **块、栏、行、表** 的空间与阅读关系，而不只是把可见字符按某种顺序串起来。

直觉：**不光抠字，还要抠「字站在哪、该先读谁」**。

- 常见误用：只会背定义，说不出和相邻组件的分工；
- 加分项：举一个线上或 demo 中的真实调用点（接口、配置项、监控指标）。

### Q5. 如何设计/实现「为何「提取到字」≠「结构对」」？（PDF 表格与版面（Layout）挑战） {#q5}

| 维度 | 说明 |
|------|------|
| 类型 | 设计题 |
| 难度 | 中等 |
| 考点 | 工程设计 · 为何「提取到字」≠「结构对」 |

**参考答法（开发向）：**

**背景要点**：一周后客服反馈：「机器人说报销上限 800 元，手册表格里明明是 500。」你打开原始 PDF——数字 500 确实被提取到了，但它和 **上一页页脚的电话号码**、**右栏另一张表的表头** 混在同一段文本里。Embedding 检索「报销上限」，命中了 **含 500 但语义错位** 的 chunk；生成模型再一润色，就变成了 800。

**设计回答框架**：
1. **目标与约束**：延迟、准确率、成本、团队规模；
2. **组件图**：列出 3～5 个模块及数据流（可手绘）；
3. **关键接口**：同步 API / 消息 / 批处理任务各负责什么；
4. **失败与降级**：超时、空检索、工具失败时的默认策略；
5. **评测**：离线指标 + 线上 shadow / 金丝雀。

**常见追问：**

- MVP 版本可以砍掉哪些部分？
- 10x 流量时最先改什么？

### Q9. 生产环境 PDF 表格与版面（Layout）挑战 出现：1. **字符数达标就上线** —— 必做结构抽检与表格核对。 2. **把 Excel 当 PDF 表解析的万能解**… —— 排查思路是什么？ {#q9}

| 维度 | 说明 |
|------|------|
| 类型 | 排障题 |
| 难度 | 中等 |
| 考点 | 线上排障 |

**参考答法（开发向）：**

**现象摘要**：1. **字符数达标就上线** —— 必做结构抽检与表格核对。 2. **把 Excel 当 PDF 表解析的万能解** —— 无线表、合并格仍会翻车。 3. **表格拆进 512 token 固定块** —— 半行数字被检索到，答案必错。 4. **忽略扫描件** —— 提取为空≠空文档，要走 OCR。 5. **双栏用「人工换行符修一下」** —— 页数上千不可持续，要上自动化版面或源文件治理。

**排查顺序**：
1. **范围**：影响面、开始时间、是否可回滚；
2. **证据链**：请求 ID → 各 hop 日志（网关 / 应用 / 向量库 / 模型 / 工具）；
3. **分层假设**：数据污染、配置变更、依赖超时、逻辑 bug——每次只验证一个；
4. **止血**：降级（缓存答案、缩小 top_k、关闭非关键工具）、限流；
5. **根因与回归**：补集成测试 + 告警阈值。

**常见追问：**

- 如何写一份给 on-call 的 runbook？
- 哪些信息必须打进结构化日志？

### Q17. PDF 表格与版面（Layout）挑战 能力要上生产，你会优先保证哪三件事？ {#q17}

| 维度 | 说明 |
|------|------|
| 类型 | 生产化 |
| 难度 | 高频 |
| 考点 | 生产落地 |

**参考答法（开发向）：**

结合 PDF 表格与版面（Layout）挑战 常见风险点：一周后客服反馈：「机器人说报销上限 800 元，手册表格里明明是 500。」你打开原始 PDF——数字 500 确实被提取到了，但它和 **上一页页脚的电话号码**、**右栏另一张表的表头** 混在同一段文本里。Embedding 检索「报销上限」，命中了 **含 500 但语义错位** 的 chunk；生成模型再一润色，就变成了 800。

**推荐三件事**：
1. **SLO 与降级**：定义 P95/P99、错误预算；检索失败/模型超时时的兜底路径；
2. **可观测**：trace_id 贯穿；记录检索命中、token、工具调用、人工介入；
3. **变更安全**：配置与 Prompt 版本化；灰度 + 自动回滚条件；回归评测门禁。

面试时用 **一个真实指标** 收尾（如 citation 准确率、empty retrieval 率）。

- 如何做成本归因到租户/业务线？
- on-call 值班最需要哪三张大盘？
