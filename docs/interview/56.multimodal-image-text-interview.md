### Q9. 做 图片内文字与多模态边界 时，哪些能力应在当前服务内实现，哪些应下沉到专用组件或另开服务？ {#q9}

|------|------|
| 类型 | 架构边界 |
| 难度 | 中等 |
| 考点 | 架构分层 |

**参考答法（开发向）：**

考察 **分层与职责单一**，避免一个服务包揽 图片内文字与多模态边界 全链路。

**通常不在同一层硬做的**（示例）：
- ** CLIP 微调、LayoutLM 训练、ColPali 索引实现、视频多模态、端侧 NPU 部署。

**答题要点**：
- 当前层只保留 **决策 + 编排 + 领域状态**；
- IO 密集（向量库、对象存储、消息队列）通过稳定接口调用；
- 说清楚 **同步调用 vs 异步任务** 的切分依据（延迟预算、失败重试）。

**常见追问：**

### Q13. 图片内文字与多模态边界 能力要上生产，你会优先保证哪三件事？ {#q13}

| 维度 | 说明 |
|------|------|
| 类型 | 生产化 |
| 难度 | 高频 |
| 考点 | 生产落地 |

**参考答法（开发向）：**

结合 图片内文字与多模态边界 常见风险点：| 问题 | 若「经常 yes」→ 建议读 | |------|------------------------| | 用户提问是否常引用 **幻灯片、架构图、监控截图**？ | ✓ | | 文档里 **关键信息在图里**（流程、拓扑、指标趋势）而不仅是图下 caption？ | ✓ | | OCR 抽出的字 **够搜但不够答**（例如问「红色模块负责什么」）？ | ✓ |

**推荐三件事**：
1. **SLO 与降级**：定义 P95/P99、错误预算；检索失败/模型超时时的兜底路径；
2. **可观测**：trace_id 贯穿；记录检索命中、token、工具调用、人工介入；
3. **变更安全**：配置与 Prompt 版本化；灰度 + 自动回滚条件；回归评测门禁。

面试时用 **一个真实指标** 收尾（如 citation 准确率、empty retrieval 率）。

**常见追问：**

- 如何做成本归因到租户/业务线？
- on-call 值班最需要哪三张大盘？
