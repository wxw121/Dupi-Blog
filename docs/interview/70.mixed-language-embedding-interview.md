### Q1. 什么是 Multilingual Embedding？在 中英混合语料 Embedding 选型 相关系统里它承担什么职责？ {#q1}

| 维度 | 说明 |
|------|------|
| 类型 | 概念题 |
| 难度 | 基础 |
| 考点 | 核心概念 · Multilingual Embedding |

**参考答法（开发向）：**

**Multilingual Embedding**（多语言嵌入）：在多种语言的文本对上训练，使「语义相同、语言不同」的句段在向量空间中靠近的表示模型。

直觉：**中文问「住宿标准」能找回英文写的 "hotel cap" 那段**——前提是模型和索引策略配对正确。

**工程语境（中英混合语料 Embedding 选型）**：
- 解决什么：把「Multilingual Embedding」讲清楚时，要落到 **输入/输出、放在链路哪一层、失败时怎么办**；
- 常见误用：只会背定义，说不出和相邻组件的分工；
- 加分项：举一个线上或 demo 中的真实调用点（接口、配置项、监控指标）。

**常见追问：**

- Multilingual Embedding 和容易混淆的替代方案怎么选？
- 如果去掉 Multilingual Embedding 这一层，最先坏掉的是哪一环？
