### Q1. 什么是 关系型数据库？在 Redis、文档库、Cache-Aside 和 TTL 一文搞懂 相关系统里它承担什么职责？ {#q1}

| 维度 | 说明 |
|------|------|
| 类型 | 概念题 |
| 难度 | 基础 |
| 考点 | 核心概念 · 关系型数据库 |

**参考答法（开发向）：**

**关系型数据库**（Relational Database）：用「表」存数据，表与表之间可以建立关联（外键、JOIN）。

直觉：像一套互相引用的 Excel 工作簿——用户表、订单表、商品表，通过 ID 串起来。

**工程语境（Redis、文档库、Cache-Aside 和 TTL 一文搞懂）**：

### Q11. 生产环境 Redis、文档库、Cache-Aside 和 TTL 一文搞懂 出现：布隆过滤器（Bloom Filter）拦截明显不存在的 key… —— 排查思路是什么？ {#q11}

| 维度 | 说明 |
|------|------|
| 类型 | 排障题 |
| 难度 | 中等 |
| 考点 | 线上排障 |

**参考答法（开发向）：**

**现象摘要**：布隆过滤器（Bloom Filter）拦截明显不存在的 key

**排查顺序**：
1. **范围**：影响面、开始时间、是否可回滚；
2. **证据链**：请求 ID → 各 hop 日志（网关 / 应用 / 向量库 / 模型 / 工具）；
3. **分层假设**：数据污染、配置变更、依赖超时、逻辑 bug——每次只验证一个；
4. **止血**：降级（缓存答案、缩小 top_k、关闭非关键工具）、限流；
5. **根因与回归**：补集成测试 + 告警阈值。

**常见追问：**

- 如何写一份给 on-call 的 runbook？
- 哪些信息必须打进结构化日志？
