### Q3. 如何设计/实现「生产依赖与开发依赖」？（从 venv 到 .venv，一文搞懂环境隔离） {#q3}

| 维度 | 说明 |
|------|------|
| 类型 | 设计题 |
| 难度 | 中等 |
| 考点 | 工程设计 · 生产依赖与开发依赖 |

**参考答法（开发向）：**

**背景要点**：你兴冲冲地用 装了爬虫库，写了个项目跑得飞起。两个月后，你接手了同事的项目，运行 ，结果报了一屏幕红字。你折腾了两个小时，发现同事的 Django 项目需要 Django 3.2，而你之前装的爬虫项目依赖 Django 4.1——两个版本在系统里打起来了。

**设计回答框架**：
1. **目标与约束**：延迟、准确率、成本、团队规模；
2. **组件图**：列出 3～5 个模块及数据流（可手绘）；
3. **关键接口**：同步 API / 消息 / 批处理任务各负责什么；
4. **失败与降级**：超时、空检索、工具失败时的默认策略；
5. **评测**：离线指标 + 线上 shadow / 金丝雀。

**常见追问：**

- MVP 版本可以砍掉哪些部分？
- 10x 流量时最先改什么？

### Q6. 从 venv 到 .venv，一文搞懂环境隔离 能力要上生产，你会优先保证哪三件事？ {#q6}

| 维度 | 说明 |
|------|------|
| 类型 | 生产化 |
| 难度 | 高频 |
| 考点 | 生产落地 |

**参考答法（开发向）：**

结合 从 venv 到 .venv，一文搞懂环境隔离 常见风险点：你兴冲冲地用 装了爬虫库，写了个项目跑得飞起。两个月后，你接手了同事的项目，运行 ，结果报了一屏幕红字。你折腾了两个小时，发现同事的 Django 项目需要 Django 3.2，而你之前装的爬虫项目依赖 Django 4.1——两个版本在系统里打起来了。

**推荐三件事**：
1. **SLO 与降级**：定义 P95/P99、错误预算；检索失败/模型超时时的兜底路径；
2. **可观测**：trace_id 贯穿；记录检索命中、token、工具调用、人工介入；
3. **变更安全**：配置与 Prompt 版本化；灰度 + 自动回滚条件；回归评测门禁。

面试时用 **一个真实指标** 收尾（如 citation 准确率、empty retrieval 率）。

**常见追问：**

- 如何做成本归因到租户/业务线？
- on-call 值班最需要哪三张大盘？
