|------|------|
| 类型 | 概念题 |
| 难度 | 基础 |
| 考点 | 核心概念 · OTA |

**参考答法（开发向）：**

**OTA**（Observe-Think-Act）：观察环境→推理→执行行动的循环。

直觉：看一眼→想一下→动手→再看结果。
