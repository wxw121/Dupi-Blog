### Q1. 什么是 Embedding？在 Embedding 向量表示 相关系统里它承担什么职责？ {#q1}

| 维度 | 说明 |
|------|------|
| 类型 | 概念题 |
| 难度 | 基础 |
| 考点 | 核心概念 · Embedding |

**参考答法（开发向）：**

**Embedding**（嵌入 / 向量表示）：把离散对象（词、句、段落、图片等）映射到 **固定长度实数向量**，使得「语义相近」的对象在空间里更靠近的表示方法。

直觉：给每段文字发一张 **多维坐标卡**，相近意思的卡片住得近。

**工程语境（Embedding 向量表示）**：
- 解决什么：把「Embedding」讲清楚时，要落到 **输入/输出、放在链路哪一层、失败时怎么办**；
- 常见误用：只会背定义，说不出和相邻组件的分工；
- 加分项：举一个线上或 demo 中的真实调用点（接口、配置项、监控指标）。

**常见追问：**

- Embedding 和容易混淆的替代方案怎么选？
- 如果去掉 Embedding 这一层，最先坏掉的是哪一环？

### Q7. 生产环境 Embedding 向量表示 出现：1. **把生成模型当 Embedding** 2. **混用模型版本** 3. **超长 chunk 盲目截断不记录*… —— 排查思路是什么？ {#q7}

| 维度 | 说明 |
|------|------|
| 类型 | 排障题 |
| 难度 | 中等 |
| 考点 | 线上排障 |

**参考答法（开发向）：**

**现象摘要**：1. **把生成模型当 Embedding** 2. **混用模型版本** 3. **超长 chunk 盲目截断不记录** 4. **相似度高 = 业务可引用**（仍要读原文与权限） 5. **忽略 query/document 非对称指令**（有的模型要加前缀）

**排查顺序**：
1. **范围**：影响面、开始时间、是否可回滚；
2. **证据链**：请求 ID → 各 hop 日志（网关 / 应用 / 向量库 / 模型 / 工具）；
3. **分层假设**：数据污染、配置变更、依赖超时、逻辑 bug——每次只验证一个；
4. **止血**：降级（缓存答案、缩小 top_k、关闭非关键工具）、限流；
5. **根因与回归**：补集成测试 + 告警阈值。

**常见追问：**

- 如何写一份给 on-call 的 runbook？
- 哪些信息必须打进结构化日志？

### Q11. 做 Embedding 向量表示 时，哪些能力应在当前服务内实现，哪些应下沉到专用组件或另开服务？ {#q11}

| 维度 | 说明 |
|------|------|
| 类型 | 架构边界 |
| 难度 | 中等 |
| 考点 | 架构分层 |

**参考答法（开发向）：**

考察 **分层与职责单一**，避免一个服务包揽 Embedding 向量表示 全链路。

**通常不在同一层硬做的**（示例）：
- ** 向量库 ANN 细节（C4）、BGE 全系列横向评测报告、Embedding 微调训练（进阶）、多模态 ColPali。

**答题要点**：
- 当前层只保留 **决策 + 编排 + 领域状态**；
- IO 密集（向量库、对象存储、消息队列）通过稳定接口调用；
- 说清楚 **同步调用 vs 异步任务** 的切分依据（延迟预算、失败重试）。

**常见追问：**

### Q15. Embedding 向量表示 能力要上生产，你会优先保证哪三件事？ {#q15}

| 维度 | 说明 |
|------|------|
| 类型 | 生产化 |
| 难度 | 高频 |
| 考点 | 生产落地 |

**参考答法（开发向）：**

结合 Embedding 向量表示 常见风险点：用户问：「轿车保养周期？」知识库写的是「汽车维护间隔」。关键词对不上时，BM25 可能很弱。若两段话被放进 **同一个语义坐标系**，坐标靠近就能召回——这就是稠密检索的直觉。

**推荐三件事**：
1. **SLO 与降级**：定义 P95/P99、错误预算；检索失败/模型超时时的兜底路径；
2. **可观测**：trace_id 贯穿；记录检索命中、token、工具调用、人工介入；
3. **变更安全**：配置与 Prompt 版本化；灰度 + 自动回滚条件；回归评测门禁。

面试时用 **一个真实指标** 收尾（如 citation 准确率、empty retrieval 率）。

**常见追问：**

- 如何做成本归因到租户/业务线？
- on-call 值班最需要哪三张大盘？
