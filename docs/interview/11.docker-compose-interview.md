### Q1. 什么是 命名空间？在 从「在我电脑上能跑」到一键起全套环境 相关系统里它承担什么职责？ {#q1}

| 维度 | 说明 |
|------|------|
| 类型 | 概念题 |
| 难度 | 基础 |
| 考点 | 核心概念 · 命名空间 |

**参考答法（开发向）：**

**命名空间**（Namespace）：让容器里的进程「以为」自己独占了一套系统——有自己的进程 ID 列表、网络接口、挂载点。通俗说：给每个容器戴一副「只看得见自己房间」的眼镜。

**工程语境（从「在我电脑上能跑」到一键起全套环境）**：
- 解决什么：把「命名空间」讲清楚时，要落到 **输入/输出、放在链路哪一层、失败时怎么办**；
- 常见误用：只会背定义，说不出和相邻组件的分工；
- 加分项：举一个线上或 demo 中的真实调用点（接口、配置项、监控指标）。

**常见追问：**

- 命名空间 和容易混淆的替代方案怎么选？
