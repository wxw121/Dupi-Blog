### Q1. 你怎么设计一个客服 Agent？ {#q1}

| 维度 | 说明 |
|------|------|
| 类型 | 综合题 |
| 难度 | 高频 |
| 考点 | 系统设计 / 表述 |

**参考答法（开发向）：**

核心是"能力分级 + 安全执行"。 意图识别后分四级：查询自动做、低风险操作自动做、 高风险操作需审批、禁止操作转人工。 工具调用走独立权限模块，不依赖 LLM 判断。 金额有硬编码上限，超过就转人工。 防注入：系统 prompt 不可覆盖，输出过滤敏感信息。 连续 3 轮不理解就转人工，避免死循环。 代码层（权限硬检查）、输出层（过滤敏感信息）。 关键是不信任 LLM 的判断，用代码做最终决策。 安全测试：注入攻击拦截率、越权操作 = 0。 宁可多转，不能让 Agent 硬撑。

**常见追问：**

- 怎么防 Prompt 注入？ 三层防御：prompt 层（指令不可覆盖）、
- 怎么评测效果？ 意图准确率、一次解决率、转人工率、CSAT。
- 什么时候转人工？ 用户要求、投诉、连续不理解、超权限、情绪激动。
