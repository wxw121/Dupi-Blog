### Q1. 什么是 流式输出？在 流式打字机效果 相关系统里它承担什么职责？ {#q1}

| 维度 | 说明 |
|------|------|
| 类型 | 概念题 |
| 难度 | 基础 |
| 考点 | 核心概念 · 流式输出 |

**参考答法（开发向）：**

**流式输出**（streaming）：服务器不是等完整答案生成完再返回，而是一小段一小段返回。

直觉：像水龙头打开后持续出水，而不是等水桶装满后一次倒给你。

**工程语境（流式打字机效果）**：
- 解决什么：把「流式输出」讲清楚时，要落到 **输入/输出、放在链路哪一层、失败时怎么办**；
- 常见误用：只会背定义，说不出和相邻组件的分工；
- 加分项：举一个线上或 demo 中的真实调用点（接口、配置项、监控指标）。

**常见追问：**

- 流式输出 和容易混淆的替代方案怎么选？
- 如果去掉 流式输出 这一层，最先坏掉的是哪一环？

### Q2. 什么是 SSE？在 流式打字机效果 相关系统里它承担什么职责？ {#q2}

| 维度 | 说明 |
|------|------|
| 类型 | 概念题 |
| 难度 | 基础 |
| 考点 | 核心概念 · SSE |

**参考答法（开发向）：**

**SSE**（Server-Sent Events）：浏览器和服务器之间的一种单向事件流。

直觉：服务器可以不断给浏览器推消息，但浏览器不能用同一条连接反向发消息。

**工程语境（流式打字机效果）**：
- 解决什么：把「SSE」讲清楚时，要落到 **输入/输出、放在链路哪一层、失败时怎么办**；

### Q3. 如何设计/实现「React Hook 最小实现」？（流式打字机效果） {#q3}

| 维度 | 说明 |
|------|------|
| 类型 | 设计题 |
| 难度 | 中等 |
| 考点 | 工程设计 · React Hook 最小实现 |

**参考答法（开发向）：**

**背景要点**：RAG 问答通常会经历检索、组织上下文、调用模型、返回引用这几个阶段。如果前端一直空白，用户很难判断系统是在工作、卡住，还是失败了。流式打字机效果解决的是“等待感”和“反馈感”。

**设计回答框架**：
1. **目标与约束**：延迟、准确率、成本、团队规模；
2. **组件图**：列出 3～5 个模块及数据流（可手绘）；
3. **关键接口**：同步 API / 消息 / 批处理任务各负责什么；
4. **失败与降级**：超时、空检索、工具失败时的默认策略；
5. **评测**：离线指标 + 线上 shadow / 金丝雀。

**常见追问：**

- MVP 版本可以砍掉哪些部分？
- 10x 流量时最先改什么？

### Q4. 生产环境 流式打字机效果 出现：只接收服务端事件时 简单；需要 POST 请求体、鉴权 Header 或中断控制时， 更灵活。… —— 排查思路是什么？ {#q4}

| 维度 | 说明 |
|------|------|
| 类型 | 排障题 |
| 难度 | 中等 |
| 考点 | 线上排障 |

**参考答法（开发向）：**

**现象摘要**：只接收服务端事件时 简单；需要 POST 请求体、鉴权 Header 或中断控制时， 更灵活。

**排查顺序**：
1. **范围**：影响面、开始时间、是否可回滚；
2. **证据链**：请求 ID → 各 hop 日志（网关 / 应用 / 向量库 / 模型 / 工具）；
3. **分层假设**：数据污染、配置变更、依赖超时、逻辑 bug——每次只验证一个；
4. **止血**：降级（缓存答案、缩小 top_k、关闭非关键工具）、限流；
5. **根因与回归**：补集成测试 + 告警阈值。

**常见追问：**

- 如何写一份给 on-call 的 runbook？
- 哪些信息必须打进结构化日志？

### Q10. 流式打字机效果 能力要上生产，你会优先保证哪三件事？ {#q10}

| 维度 | 说明 |
|------|------|
| 类型 | 生产化 |
| 难度 | 高频 |
| 考点 | 生产落地 |

**参考答法（开发向）：**

结合 流式打字机效果 常见风险点：RAG 问答通常会经历检索、组织上下文、调用模型、返回引用这几个阶段。如果前端一直空白，用户很难判断系统是在工作、卡住，还是失败了。流式打字机效果解决的是“等待感”和“反馈感”。

**推荐三件事**：
1. **SLO 与降级**：定义 P95/P99、错误预算；检索失败/模型超时时的兜底路径；
2. **可观测**：trace_id 贯穿；记录检索命中、token、工具调用、人工介入；
3. **变更安全**：配置与 Prompt 版本化；灰度 + 自动回滚条件；回归评测门禁。

面试时用 **一个真实指标** 收尾（如 citation 准确率、empty retrieval 率）。

**常见追问：**

- 如何做成本归因到租户/业务线？
- on-call 值班最需要哪三张大盘？
